# أمانة — التحقق من سلامة المعنى في ترجمات معاني القرآن الكريم

[English](README.md) · **العربية**

يتحقق «أمانة» من أن الترجمة الإنجليزية لآية من القرآن الكريم تحفظ معناها. يقارن الترجمة بنص الآية الموثّق، ويُصدر قرارًا واضحًا من نموذج «أمانة» المتخصص الذي بناه الفريق، ويحيل ما يحتاج إلى نظر إلى مراجع بشري قبل النشر.

مشروع مقدَّم إلى **«تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي»**.

- **الموقع التجريبي:** <https://ma.mahmoude4477.workers.dev> (بيانات الدخول في العرض التقديمي)
- **نموذج «أمانة» (الشيفرة وخط البيانات والتقييم):** [Amanah AI model](https://github.com/Saahar2001/Amanah-/tree/main/Amanah%20AI%20model)

## ماذا يفعل

قد تكون الترجمة سليمةً لغويًا وتُغيّر المعنى مع ذلك: نفيٌ ينقلب، أو شرطٌ يسقط، أو لفظٌ شرعي يُستبدل بغيره. ويقوم «أمانة» بما يلي:

1. يأخذ موضع الآية (مثل `2:279`) ويجلب نصها العثماني الموثّق بنفسه.
2. يأخذ الترجمة الإنجليزية المراد فحصها.
3. يُصدر نموذج «أمانة» قراره: `PASS` أو `REVIEW` أو `CRITICAL` أو `ABSTAIN`، مع درجة الخطورة ومؤشر سلامة المعنى ونوع الانحراف.
4. يضيف نموذج لغوي شرحًا عربيًا مختصرًا، ولا يملك الشرح تغيير القرار.
5. يعتمد الإنسان الترجمة أو يعيدها للتصحيح، ويُحفظ كل فحص وقرار في السجل.

## المزايا

- **نص قرآني موثّق:** لا يكتب المستخدم الآية، بل تأتي من نص مشروع تنزيل على الخادم؛ وإذا أرسل عميل الواجهة البرمجية نصًا عربيًا لا يطابقها حرفيًا، توقّف الفحص مع بيان موضع الاختلاف.
- **قرار من نموذج متخصص:** يكشف «أمانة» انحراف المعنى، مثل: انقلاب النفي، والحذف، وتغيّر صيغة الحكم، وتغيّر الكمّ، وسقوط الشرط، وانقلاب الإسناد.
- **الشرح لا يغيّر القرار:** النموذج اللغوي يشرح فقط.
- **الامتناع بدلًا من التخمين:** إذا تعذّر الحكم بثقة كانت النتيجة `ABSTAIN` وأُحيلت إلى الإنسان.
- **الاعتماد للإنسان:** لا يُعتمد شيء دون سبب مكتوب، ولا تُتجاوز النتيجة الحرجة `CRITICAL` إلا بقرار مراجع مستقل مع تعليل علمي.
- **قاموس المصطلحات:** تُفحص المصطلحات العشرة في مرجعية التحدي (مثل الوحي والشريعة والعبادة) للتنبيه إلى الترجمة المختزلة.
- **سجل كامل:** يُحفظ لكل فحص نص الآية والترجمة وقرار النموذج وقرار المراجع، ويمكن تصدير السجل، وحذف الحساب وجميع بياناته.
- **واجهة عربية** تُفصح بوضوح عن استعمال الذكاء الاصطناعي.

## البدء السريع

المتطلبات: **Node.js 22.13 أو أحدث** و**Git**. ويأتي pnpm عبر corepack.

```bash
# 1. نزّل الشيفرة
git clone https://github.com/Saahar2001/Amanah-.git
cd "Amanah-/Amanah Website"
# (أو: git clone https://github.com/mahmoude4477/amanah.git && cd amanah)

# 2. ثبّت الاعتماديات
corepack enable
pnpm install --frozen-lockfile

# 3. أنشئ ملف الإعدادات المحلي
cp .env.example .dev.vars
```

افتح `.dev.vars` وضع في `BETTER_AUTH_SECRET` قيمة عشوائية لا تقل عن 32 حرفًا، ويمكن توليدها بالأمر:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('base64url'))"
```

```bash
# 4. أنشئ قاعدة البيانات المحلية
npx wrangler d1 migrations apply ma-db --local

# 5. أنشئ حسابك الأول (التسجيل الذاتي معطّل)
node scripts/create-user.mjs --email you@example.com --name "Your Name" --role admin

# 6. شغّل التطبيق
pnpm dev
```

يطبع سكربت الحساب كلمة مرور مولَّدة مرة واحدة. افتح العنوان الذي يطبعه `pnpm dev` (مثل `http://localhost:5173`) وسجّل الدخول بالبريد وكلمة المرور.

**ملاحظات**

- يستعمل `pnpm dev` خدمة Cloudflare Workers AI للشرح، فنفّذ `npx wrangler login` مرة واحدة. وللتشغيل دون أي اتصال: `AMANAH_DEV_LOCAL_ONLY=1 pnpm dev` (وفي PowerShell: `$env:AMANAH_DEV_LOCAL_ONLY='1'; pnpm dev`)، فيظهر الشرح «غير متاح» ويبقى القرار كما هو.
- الخيار `--role admin` يجعل الحساب مراجعًا مستقلًا أيضًا، فاحذفه لحساب مستخدم عادي.
- إذا لم تُضبط إعدادات النموذج (القسم التالي) يعمل التطبيق، لكن طلب التحليل يعيد `503 CONFIGURATION_REQUIRED`.
- أول تشغيل لـ `pnpm dev` يجهّز الاعتماديات وقد يستغرق دقائق، وإن توقف بالخطأ `read ECONNRESET` فأعد تشغيله.

## ربط نموذج «أمانة»

أضف رابط النموذج ومفتاحه إلى `.dev.vars` (وأسرارًا للعامل في الإنتاج):

```env
AMANAH_ML_URL=<رابط خدمة النموذج>
AMANAH_ML_TOKEN=<مفتاح الخادم>
```

لديك خياران:

1. **نقطة الفريق على Hugging Face:** اطلب من الفريق رابط النقطة ومفتاح وصول.
2. **تشغيل خدمة النموذج بنفسك:** في مجلد [Amanah AI model](https://github.com/Saahar2001/Amanah-/tree/main/Amanah%20AI%20model) خدمة FastAPI (`uvicorn api.main:app --port 8000`)، وتحتاج حزمة النموذج المدرَّب؛ انظر ملف README في ذلك المجلد و`docs/REPRODUCIBILITY.md`. ثم اضبط `AMANAH_ML_URL=http://localhost:8000` (لا يُقبل `http` إلا مع `localhost` و`127.0.0.1`).

الروابط المنتهية بـ `.endpoints.huggingface.cloud` تُستدعى بطريقة Hugging Face، وغيرها يُستدعى عبر واجهة النموذج `POST {AMANAH_ML_URL}/v1/analyze`. ويمكن تحديد ذلك صراحة بضبط `AMANAH_ML_TRANSPORT` على `hf` أو `fastapi`.

يُستدعى النموذج من الخادم فقط، ولا يصل المفتاح إلى المتصفح.

**الطلب** الذي يرسله التطبيق:

```json
{
  "inputs": {
    "source_type": "quran",
    "source_ar": "نص الآية العربي الموثّق",
    "candidate_en": "الترجمة الإنجليزية المراد فحصها",
    "ayah_id": "2:279"
  }
}
```

**حقول الاستجابة** التي يعتمدها التطبيق: `decision` و`integrity_score` و`severity` و`confidence` و`drifts` و`needs_human_review` و`model_version` و`reference_status` و`notes`. وهذه الحقول هي التي تحدد النتيجة، ولا يكتب فوقها شرح النموذج اللغوي.

وتعرض الواجهة نطاق النموذج المقاس بالشارة «النسخة المقاسة v0.2 · العربية ← الإنجليزية».

## استخدام الموقع

1. سجّل الدخول، ثم اضغط **«تحليل جديد»**.
2. اختر السورة والآية، أو اكتب الموضع مثل `2:279` في **«أو اكتب رقم الآية»** واضغط **«عرض الآية»**، فيظهر النص العثماني تلقائيًا.
3. ألصق الترجمة الإنجليزية في **«الترجمة المراد فحصها»** واضغط **«تحليل»**.
4. اقرأ القرار ودرجة الخطورة ومؤشر سلامة المعنى ونوع الانحراف والشرح.
5. افتح الفحص من **«فتحه في السجل والمراجعات»**، واكتب السبب، ثم اختر **«اعتماد هذه النسخة»** أو **«إعادة للتصحيح»**.

## قواعد المراجعة

- **المسودة الداخلية:** يقرر فيها صاحب الفحص.
- **النشر الرسمي:** لا يقرر فيه صاحبه، بل ينتظر **مراجعًا مستقلًا** (مستخدم دوره `admin`، أو بريده في `AMANAH_REVIEWER_EMAILS`).
- **الاعتماد** يتطلب سببًا مكتوبًا وتأكيد مقارنة الترجمة بنص الآية؛ أما الإعادة للتصحيح فتكفيها كتابة السبب.
- **`CRITICAL`** لا يعتمده صاحبه، ولا يعتمده إلا مراجع مستقل بتفعيل التجاوز الموثّق وكتابة تعليل علمي.
- **`ABSTAIN`** لا يُعتمد أبدًا، ويُعاد للتصحيح فقط.
- القرار بعد حفظه نهائي، ويُسجل معه اسم المراجع ودوره ووقت القرار.

## النشر على Cloudflare

```bash
npx wrangler login
npx wrangler secret put BETTER_AUTH_SECRET
npx wrangler secret put AMANAH_ML_URL
npx wrangler secret put AMANAH_ML_TOKEN
npx wrangler d1 migrations apply ma-db --remote
pnpm run build
npx wrangler deploy
node scripts/create-user.mjs --email you@example.com --name "Your Name" --role admin --remote
```

- تُضبط القيم **أسرارًا** (Secrets) لا متغيرات عادية، حتى لا يحذفها النشر التالي، ولا تُكتب في `wrangler.jsonc` ولا في الشيفرة.
- **على حسابك في Cloudflare:** أنشئ قاعدة بالأمر `npx wrangler d1 create ma-db` وضع معرّفها في `wrangler.jsonc`، وأضف نطاق موقعك إلى `allowedHosts` في `lib/server/auth.ts`.

## متغيرات البيئة

| المتغير | الغرض |
|---|---|
| `BETTER_AUTH_SECRET` | سر تسجيل الدخول، 32 حرفًا على الأقل. إلزامي. |
| `AMANAH_ML_URL` | رابط نموذج «أمانة» (`https://`). بدونه يعيد التحليل 503. |
| `AMANAH_ML_TOKEN` | مفتاح Bearer للنموذج. |
| `AMANAH_ML_TRANSPORT` | اختياري: `hf` أو `fastapi`، ويُستنتج من الرابط إن تُرك فارغًا. |
| `AMANAH_ML_TIMEOUT_MS` | اختياري: مهلة النموذج بالمللي ثانية (الافتراضي 240000 لـ `hf`). |
| `AMANAH_REVIEWER_EMAILS` | اختياري: بريد المراجعين المستقلين مفصولًا بفواصل. |
| `AMANAH_DEV_LOCAL_ONLY` | للتطوير فقط: `1` يشغّل `pnpm dev` دون أي اتصال بـ Cloudflare، ويُضبط في الطرفية. |

الشرح الكامل في [`.env.example`](.env.example).

## النص القرآني والنموذج والتراخيص

- **النص القرآني:** نص مشروع تنزيل (Tanzil Quran Text 1.1) برواية حفص عن عاصم بالرسم العثماني، ويُنقل حرفيًا. حقوق النشر © 2007-2026 مشروع تنزيل، بترخيص Creative Commons Attribution 3.0 (<https://tanzil.net>)، والتفاصيل في [`vendor/README.md`](vendor/README.md). وقد طابقناه بمصحف مجمع الملك فهد لطباعة المصحف الشريف (رواية حفص)، فتطابق النصان حرفًا بحرف في جميع الآيات (6236 آية).
- **نموذج «أمانة»:** AMANAH Semantic Integrity v0.2 من فريق «أمانة»، مُدرَّب بالضبط الدقيق لنموذج mDeBERTa-v3. النطاق المقاس: من العربية إلى الإنجليزية. وتفوّق الإصدار الثاني على الأول في تقييم الفريق (مقياس F1 الكلي 95.26% مقابل 92.15%). ودعم لغات أخرى من خطة المشروع.
- **التقنيات:** Vinext (Next.js على Cloudflare Workers)، وReact، وCloudflare D1، وDrizzle، وBetter Auth، وCloudflare Workers AI (Llama 3.3 70B للشرح فقط)، وTailwind CSS، وshadcn/ui.
- **الخطوط والمكوّنات:** Noto Sans Arabic بترخيص SIL Open Font License، وThmanyah Sans وفق سياسة الاستخدام لدى ثمانية ([`public/fonts`](public/fonts))؛ وPhosphor Icons وأنماط shadcn/ui وإضافة sites-vite-plugin بترخيص MIT، ونصوص تراخيصها مرفقة.
- **المرجعية العلمية:** المرجعية والحزمة العلمية والبيانات لـ«تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي».
